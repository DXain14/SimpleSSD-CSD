# Contributing

Contributions should explain the simulator behavior being changed and include
focused tests or a reproducible test command.

By submitting a contribution, you confirm that you have the right to submit
it and that it may be distributed under the repository's GPLv3 terms. Preserve
existing copyright, license, and third-party notices. Do not submit generated
build output, private data, credentials, or material copied from an
incompatible license.

This project does not currently request copyright assignment or a separate
contributor license agreement.
